## 实施结果

- 统一编辑文档保存主轨、字幕、公共图文层、旁白和 BGM。30 fps 包含尾帧，稳定身份与单调编号；主轨编号仍按顺序显示。
- 图像、音频和 SRT 上传仅在已有任务开放。图音上传不自动加入成片，SRT 使用整轨替换候选。真实格式、解码、方向、透明度、数量及并发占位均由服务端校验。
- 属性与对话共用候选和保存服务；候选代次、内容哈希、版本检查及操作结果查询保护确认。刷新后可在属性页点击“编辑当前候选参数”继续修改，沿用原操作标识。
- Fontkit / Unicode 换行 / Resvg 在服务端将文字转为路径和透明 PNG。普通及粗体 Noto Sans CJK SC 与 OFL、固定来源及 SHA-256 归档在 `packages/shared/assets/fonts/`。
- Remotion 4.0.541 使用相同图文 PNG 和整段混音；关闭片段自身声音。前端 Mediabunny 固定为 Remotion 所用的 1.64.0，避免双版本解码器。
- 48 kHz 双声道、每帧 1600 样本，处理源选段、固定/全片窗口、循环、线性淡化和音量。浮点 PCM 叠加，AAC 解码后复测峰值，预览与 MP4 复用同一 AAC 文件。
- MP4 / SRT 使用独立 v4 不可变快照、状态及下载入口。保留 v2/v3 历史生成兼容、原快照重试、流式保存和取消清理。
- 增量迁移 0008～0010 已验证；无归属旧任务、旧时间轴及旧快照不重新分配账号。

## 验收入口

1. 按 README 启动数据库、API、Web / Electron，使用测试验证码登录并导入视频，先确认至少一个主轨 Clip。
2. 在“图音与字幕文件”中上传图像、声音或 SRT。在右侧“属性”选择“＋字幕”“＋标题/文字”“＋图像”“＋声音”，或选中已有元素。
3. 修改参数后生成完整候选，在左侧观看完整合成；准备及播放器装载成功后才能确认。更改参数会立即禁用原候选确认。
4. 可取消候选；确认后刷新仍保留。候选失败与正式预览失败分别重试，正式预览失败不撤销已保存定义。
5. “下载成品”和“导出 SRT”分别创建作业，完成后再次点击“保存 MP4/SRT vN 到本地”。生成中可继续编辑。

时间输入是“分:秒:帧”，例如 `00:05:00` 到 `00:08:00` 共 91 帧。图音默认参数和主轨变更影响在候选中列出，明确输入越界会拒绝，不静默裁切。

当前候选会准备整段声音，长片可能需要数分钟。只改图文时复用混音；取消/遗弃候选的无引用缓存保留 24 小时后清理，已保存预览依赖继续保留。任务删除统一清理。

## 重跑验证

使用 pnpm 9.15.9。当前机器的隔离启动方式是 `node node_modules/.tools/pnpm9/bin/pnpm.cjs <命令>`；标准环境可直接使用对应版本的 `pnpm`。

服务端集成测试自动使用独立的临时数据库，数据库账号需要创建数据库权限；运行结束会回收该数据库。Redis 队列和文件目录仍按测试独立隔离。

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm --filter @cev/server test:integration
pnpm build
$env:CEV_E2E_REAL_API='1'
pnpm --filter @cev/e2e exec playwright test --workers=1
pnpm format:check
git diff --check
```

最大文档性能测试单独启用，避免与真实模型联调同时争用 CPU 和磁盘：

```powershell
$env:CEV_D1_PERFORMANCE='1'
pnpm --filter @cev/server exec vitest run --project integration test/integration/composition-load.spec.ts
```

该测试真实生成 30 分钟混音并使用数 GiB 临时磁盘，自动删除本次测试目录。性能 JSON 写入服务端 `storage/d1-performance.json`。
